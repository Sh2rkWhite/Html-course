Шістнадцятична система числення та RGB

1. Що таке шістнадцятична система?

Шістнадцятична система (HEX) використовує 16 символів для запису чисел:

  • Цифри: від 0 до 9
  • Букви: A (10), B (11), C (12), D (13), E (14), F (15)

Діапазон значень для одного байта: від 00 (0) до FF (255).

2. Формування коду кольору RGB

Колір записується у форматі: #RRGGBB

  • RR — інтенсивність червоного (00–FF)
  • GG — інтенсивність зеленого (00–FF)
  • BB — інтенсивність синього (00–FF)

3. Приклади базових кольорів

Колір HEX-код Склад кольору
Червоний #FF0000 Червоний на максимум, інші 0
Зелений #00FF00 Зелений на максимум, інші 0
Синій #0000FF Синій на максимум, інші 0
Білий #FFFFFF Усі кольори на максимум
Чорний #000000 Усі кольори на 0
